# 天翼云电脑自动化 - Windows 桌面版

Windows 桌面绿色版：**解压即用，双击 `CtYun.exe` 启动**，功能与 Docker 版完全一致（自动登录、保活攒积分、AI 对话、积分兑换、Web 管理面板）。

## 系统要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10 / 11（64 位） |
| 浏览器 | 无需安装，自动使用系统自带 Microsoft Edge（装有 Chrome 也可） |
| Python | 无需安装，运行时已随包内置 |
| .NET | 无需安装，运行时已随包内置 |

## 快速开始

1. 将整个 `CtYun` 文件夹解压到任意位置（**路径建议不要含特殊字符**，且文件夹需可写——数据会存在里面的 `data\` 目录）
2. 双击 `CtYun.exe`
3. 浏览器访问管理面板：<http://127.0.0.1:8090>
4. 首次使用在面板中填写天翼云账号（手机号 + 密码），保存即可

## 目录结构

```
CtYun\
├── CtYun.exe        ← 双击启动（唯一入口）
├── runtime\         ← 内置 Python 运行时（面板与任务脚本）
├── dotnet\          ← 内置 .NET 运行时（保活核心）
├── ctyun-core\      ← CtYun.dll 保活核心
├── web_server\      ← Web 面板后端
├── web\             ← Web 面板前端
├── app\             ← 登录 / 挂机 / AI 对话 / 兑换任务脚本
└── data\            ← 你的全部数据（账号、日志、配置）——备份只需复制这个目录
```

## 使用说明

- **控制台窗口**：双击 exe 后会出现一个黑色控制台窗口，显示运行日志；**关闭窗口即退出程序**（面板、保活全部停止）。
- **保活**：默认连接 5 分钟 → 断开 15 分钟循环；间隔可在面板「保活设置」调整，关闭开关即停止保活。
- **AI 对话 / 挂机 / 兑换**：在面板「任务」页手动触发，或在「定时任务」配置每天自动执行。
- **单实例保护**：程序已在运行时再次双击 exe 会被自动拒绝（防止端口冲突和账号互踢）。
- **数据安全**：所有数据只保存在本机 `data\` 目录，不上传任何服务器；账号密码仅存于本地 `data\web_settings.json`。

## 常见问题

**Q：双击后闪退？**
先用命令行运行查看报错：`Win+R` 输入 `cmd`，把 `CtYun.exe` 拖进窗口回车。常见原因：解压不完整（缺 runtime 或 dotnet 目录）、所在盘/目录不可写。

**Q：8090 端口被占用？**
编辑启动方式：`CtYun.exe` 无法直接改端口时，可在命令行用环境变量启动：
```bat
set WEB_PORT=9090 && CtYun.exe
```

**Q：杀毒软件报警？**
本程序未购买商业代码签名证书时，可能被部分杀软误报。可在杀软中添加信任，或参考下方「代码签名说明」。

**Q：怎么彻底卸载？**
直接删除整个 `CtYun` 文件夹即可（程序不写注册表、不装系统服务；`data\` 里是你的账号数据，删前如有需要自行备份）。

## 代码签名说明

- 当前发布的 `CtYun.exe` 使用**自签名证书**签名：仅保证文件自发布后未被篡改，**不能消除杀软提示**（自签名不含受信任的第三方背书）。首次运行如遇「SmartScreen 已保护你的电脑」，点击「更多信息 → 仍要运行」即可。
- 如需彻底消除提示，需购买商业代码签名证书（个人开发者可选 OV 型，年费约几百到两千元不等），签发后用 `signtool sign /fd SHA256 /tr <时间戳服务器> /td SHA256 CtYun.exe` 签名。

## 与 Docker 版的对应关系

| Docker 版 | 桌面版 |
|-----------|--------|
| `docker compose up -d` | 双击 `CtYun.exe` |
| 容器日志 `docker logs` | 控制台窗口 |
| Web 面板 `8090:8080` | <http://127.0.0.1:8090> |
| 挂载 `./data` | `CtYun\data\` |
| `/tmp` 信号文件 | `data\.tmp\` |

桌面版与 Docker 版由同一套核心代码驱动，功能、面板界面、API 完全一致。
